# Age Calculator

A simple and responsive **Age Calculator** built with **HTML, CSS, and JavaScript**.

The application allows users to enter their date of birth and calculates their current age based on today's date. The result is displayed in **years, months, and days**.

## Features

* Date of birth input
* Calculates the user's current age
* 📊 Displays age
* Instant calculation
* Handles different month lengths
* Responsive design
* Clean and simple interface
* Prevents invalid future birth dates

## Technologies Used

* **HTML5** — Creates the structure of the age calculator.
* **CSS3** — Handles the styling, layout, and responsive design.
* **JavaScript** — Performs the age calculation and dynamically updates the result.

## How It Works

The user selects their **date of birth** using the date input.

JavaScript then compares the birth date with the current date and calculates the difference.

For example, if someone was born on **January 15, 2010**, the calculator compares that date with the current date and calculates their current age.

The calculation also accounts for differences in the number of days in each month rather than simply dividing the total number of days by 365.
